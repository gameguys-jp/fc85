# SAMPLE 7（C で書いたラスタのパレットのカートリッジ）

**v0.1**  
2026年11月27日

> 状態：作業中の版。C で書いた最初のサンプル（DR-111）。HBlank の割込みでパレットの色をラインごとに替える本機の表現を、SDK の C の関数（`video.h`。[c.md](../../docs/c.md) §09、DR-109）だけで書く。機械仕様は [仕様書](../../../docs/spec/hardware.md)、BIOS の約束は [bios-abi.md](../../docs/bios-abi.md)、C の手引きは [c.md](../../docs/c.md) が正。このサンプルで決めた値はすべて [P] で、エージェントが決めた（ユーザーが判断を任せた。要見直し）。題名の `SAMPLE 7` は中立な仮の名前で、製品名ではない。

記述ステータス：`[D]` 原典に根拠のある IC の仕様、`[P]` 本機独自の暫定設計値、`[O]` 代替・拡張候補、`[V]` 要検証（ここではエミュレータで測った値も [V] とする）。

## 01　概要

| 出すもの | 中身 |
|---|---|
| ラスタの帯 | 背景の色 0 を、HBlank の割込みで 8 ラスタごとに替える（画面の 24 帯、1 フレームに 23 回の割込み）。色は R・G・B の三角波を 1/3 周ずつずらした 32 色の虹で、隣どうしはいつも違う。VBlank のフックが最初の帯の色と最初の区切りに戻し、階調を 1/16 帯ずつずらす |
| DIRECT（Bend） | A で `PAL_CTRL` の DIRECT を切り替える。色が表へ直接入るので、帯の境がラスタの途中（エミュレータでは x＝199〜212 の辺り。割り込まれた命令で数ドット動く [V]）に移る |
| DOC の音（子基板があるとき） | B で三角波（オシレータ 0、CA 0、L）を鳴らす・止める。高さは帯の流れについて 1 オクターブを上り下りする。子基板がなければ `NO DOC` と出す |
| 字 | 題名、速さ、DIRECT と音の入切。字のない列（x＝240 より右）に帯がそのまま見える |

- 像は約 2 KB。`$400000` から置く。C の関数（`video.c`・`video_irq.S`・`doc.c`・`fabric.c` ほか）は組立ての道具が一緒に組み、使わない関数はリンクで落ちる。
- ラスタ L の HBlank で書いた色はラスタ L＋2 から効く（[c.md](../../docs/c.md) §09）。帯 k は画面の y＝8k から始めたいので、`VIDEO_TOP_RASTER + 8k − 2` で比べる。
- 割込みの処理（`band`）は C のふつうの関数。`video_hblank` が置く入口（`video_irq.S`）が HBL の保留を消して呼び、BIOS の処理へつなぐので、`bios_wait_vbl` と `bios_vbl_hook` はそのまま使える。

## 02　組み方と動かし方

リポジトリの根で：

```
py sdk/samples/raster/build.py
cd emulator
cargo run --release -p fc85-host -- --cart ../sdk/samples/raster/build/raster.bin
```

68000 の GCC が要る（[c.md](../../docs/c.md) §02。Ubuntu・WSL なら `gcc-m68k-linux-gnu`）。GCC がなければ `build.py` は組まずに 2 を返し、試験は飛ばす。

| キー | 働き |
|---|---|
| 上・下 | 流れる速さ（0〜15。1 フレームに 1/16 帯の単位） |
| A | DIRECT（Bend）の入切 |
| B | DOC の音の入切 |
| START | 速さを 4 に戻し、DIRECT と音を切る |

## 03　試験

`py -m unittest discover -s sdk/samples/raster`。GCC があれば組んで見出しを確かめる。エミュレータの窓口（`fc85-api`）と Boot ROM もあれば動かし、画面の PNG の字のない列で、帯の境が y＝8k（k＝0〜23）にあり、色が階調を続けて並べたものであること、1 フレームに 23 回の HBlank、帯が流れること、A の後は境がラスタ 8k−1 の途中に移ること、B で音が出ること（子基板があるとき）、START で戻ることを確かめる。
