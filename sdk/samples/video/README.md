# SAMPLE 4：ACRTC の表示

HD63484 ACRTC の表示の機能（分割画面、ウィンドウ、ズーム、スムーズスクロール、点滅するカーソル）を見せる
カートリッジ。エミュレータの表示の模型を目で確かめるためのもので、遊ぶものではない。

## 01　組み方と動かし方

```
py sdk/samples/video/build.py
cd emulator
cargo run --release -p fc85-host -- --cart ../sdk/samples/video/build/video.bin
cargo run --release -p fc85-host -- --headless --frames 100 --cart ../sdk/samples/video/build/video.bin --dump-at 70,78 --dump <scratchpad>/video.ppm
```

試験は `py -m unittest discover -s sdk/samples/video`（組んだ像の見出しと、レジスタの値の計算）。

## 02　画面

案B（256×192、台帳 HD63484.md §3.4）の 192 ラスタを、DCR で 3 つの分割画面に分け、ウィンドウを重ねる。

| 画面 | ラスタ | VRAM（語番地） | 見せるもの |
|---|---|---|---|
| 上画面 | 43〜90（48） | $4000〜、MW 64、112 行 | 縦のスムーズスクロール。毎フレーム SAR0 を MW（1 行）ずつ進め、64 行で戻る |
| ウィンドウ | 51〜82（32）、x 160〜223 | $7000〜、MW 64 の左 16 語 | 上画面に重ねる。前読みがないので、DISP2 より 4 ドット右に出る（emulator.md §03）[V] |
| 基本画面 | 91〜210（120） | $0000〜、MW 64 | 縦横 2 倍のズーム（ZFR＝$1100）。左上の 128×60 画素が見える。点滅するグラフィックカーソル（x 112〜127、ラスタ 140〜155。8 フィールド点き 8 フィールド消える） |
| 下画面 | 211〜234（24） | $6000〜、MW 128、24 行 | 横のスムーズスクロール。毎フレーム 1 画素：SAR2 の語（4 画素ごと）と SDA（0〜3 画素） |

- 基本画面の横のズームは、ラスタごとの属性（HZ）で外の回路がシフトレジスタを遅くするので、そのラスタの
  ウィンドウも同じ倍率で崩れる。それでウィンドウは上画面に置いた。
- カーソルは、CUD1 が出ている画素のパレットの番号を反転（XOR $F）する本機の回路で見える [P]。
- レジスタは VBlank の中で書く。ACRTC はラスタの頭にレジスタを読むので、次のフレームの頭から効く。
- 画面の設定を先にし、描画の途中も表示している。起動の直後は、描いている途中の画面が見える。

## 03　確かめたこと

`--dump-at 70,78` の画面で、上画面が 70 と 78 で 8 行ずれ、下画面の目盛りが 8 画素ずれ、カーソルが 70 で
点き 78 で消えている。
