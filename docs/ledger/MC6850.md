## 2. ピンと本機での接続

24ピンDIP。ピン番号は M1 の拡張ブロック図（Figure 9）による [D M1 3-498]。本機の接続は仕様書§05（0x260000–2600FF）と§09（MIDI_STATUS=+0x14、MIDI_DATA=+0x16、上位byte lane）からの暫定案。

| 信号 | 方向 | 機能 | 本機での接続 | 状態 |
|---|---|---|---|---|
| VSS (1) | — | GND | GND | [D M1 3-498] |
| Rx Data (2) | 入力 | シリアル受信データ（TTL互換、高インピーダンス） | MIDI IN のフォトカプラ出力 | 機能 [D M1 3-500]／接続 [P]、部品 [V] |
| Rx CLK (3) | 入力 | 受信クロック。立上りでサンプル。÷1モードでは外部同期が必要 | 500 kHz（後述のクロック案） | [D M1 3-499]／[P] |
| Tx CLK (4) | 入力 | 送信クロック。立下りで送信データを出す | Rx CLK と同じ 500 kHz | [D M1 3-499]／[P] |
| RTS̅ (5) | 出力 | Request-to-Send。CR5・CR6で制御 | 未使用、またはMIDI THRU切替・表示用 | [D M1 3-500]／[O] |
| Tx Data (6) | 出力 | シリアル送信データ | MIDI OUT ドライバ（DIN 5ピン） | [D M1 3-500]／回路 [V] |
| IRQ̅ (7) | 出力 | 割込み要求。オープンドレイン、内部プルアップなし、負論理 | プルアップして入力割込み集約（仕様書§09 INPUT_IRQ_STATUS）へ | [D M1 3-499]／[P] |
| CS0 (8) | 入力 | チップセレクト（正論理）。CS0・CS1が高、CS2̅が低で選択 | アドレスデコード出力（0x260014–0x260017） | [D M1 3-499]／[P] |
| CS2̅ (9) | 入力 | チップセレクト（負論理） | 68000 の VMA̅（負論理）を直結 | 機能 [D M1 3-499]／接続 [P]、[V]（タイミング未検証） |
| CS1 (10) | 入力 | チップセレクト（正論理） | +5 V固定、またはAS̅条件付きデコード | [D M1 3-499]／[P] |
| RS (11) | 入力 | 高でTDR/RDR、低で制御/状態レジスタ | A1（+0x14→RS=0、+0x16→RS=1） | [D M1 3-499]／[P] |
| VCC (12) | — | +5 V ±5% | +5 V | [D M1 3-495, 3-498] |
| R/W̅ (13) | 入力 | 高で読出し、低で書込み | 68000 R/W̅ | [D M1 3-499] |
| E (14) | 入力 | Enable。バス転送のクロック。6800のφ2または6809のEに相当 | 68000 の E（CLK/10） | [D M1 3-499; M2 §4.1.7.1] |
| D7–D0 (15–22) | 双方向 | データバス。読出し時以外はハイインピーダンス | 68000 の D15–D8（上位バイトレーン、偶数番地） | [D M1 3-498, 3-499]／[P] |
| DCD̅ (23) | 入力 | Data Carrier Detect。高で受信部を禁止・初期化し、立上りで割込み | GNDに固定（高にすると受信しない） | [D M1 3-500] |
| CTS̅ (24) | 入力 | Clear-to-Send。高でTDREを抑止 | GNDに固定（高にすると送信空きが立たない） | [D M1 3-500] |

68000側の付帯信号：VPA̅ はアドレスをAS̅で条件付けしてデコードし、6800系周辺のチップセレクトはVMAで条件付けする [D M2 §6.1]。周辺はEの高期間にサイクルを実行する [D M2 §6.1]。68000のVMA̅は6800と逆の負論理である [D M2 §6.1]。

MIDI物理層（フォトカプラ品番、5 mA電流ループ、220 Ω抵抗等）は本台帳の範囲外。MIDI 1.0規格原典（1983年）は未照合 [V]。

### 3.5 MIDI 31.25 kbit/s の入力クロック

| 方式 | 入力クロック | 判定 | 根拠 |
|---|---|---|---|
| ÷16 | 500 kHz | 可。0.8 MHz以下。50%デューティなら各1000 ns ≥ 600 ns | [D M1 3-496]、[D: 計算] |
| ÷64 | 2 MHz | 不可。全速度品の上限（0.8／1.0／1.5 MHz）を超える | [D M1 3-496]、[D: 計算] |
| ÷1 | 31.25 kHz | 受信には外部でのビット同期が必要。MIDI IN には不適 | [D M1 3-499] |
| 500 kHz の作り方 | 16 MHz÷32、8 MHz÷16、20 MHz÷40 は誤差0。6fsc（21.47727 MHz）÷43 は499.47 kHz（−0.11%）。8fsc÷57 は+0.48%。4fsc÷29 は−1.25% | [D: 計算]。詳細は clock-video-1985.md §5 |
| MIDIの許容誤差 | 31250 baud ±1%、1スタート・8データ・1ストップ | [D MI1]（後年の要約。1983年規格原典は未照合 [V]） |
| 1バイト時間 | 10ビット＝320 µs。3バイトメッセージ0.96 ms | [D: 計算]（仕様書§09の0.96 msと一致） |

受信の同期：÷16モードでは受信線の低サンプルを8個検出してビット同期を始める。偽スタートビット除去により、半ビット分のスタートビットを確認してから同期する [D M1 3-499]。

## 4. レジスタ・制御

### 4.1 アドレス [D M1 3-500 Table 1, 3-499]

| RS | R/W̅ | レジスタ | 本機の番地（仕様書§09） |
|---|---|---|---|
| 0 | 0 | 制御レジスタ（書込み専用） | 0x260014（MIDI_STATUS 書込み） |
| 0 | 1 | 状態レジスタ（読出し専用） | 0x260014（MIDI_STATUS 読出し） |
| 1 | 0 | 送信データレジスタ TDR（書込み専用） | 0x260016（MIDI_DATA 書込み） |
| 1 | 1 | 受信データレジスタ RDR（読出し専用） | 0x260016（MIDI_DATA 読出し） |

### 4.2 制御レジスタ [D M1 3-501]

| ビット | 名称 | 内容 |
|---|---|---|
| CR1:CR0 | Counter Divide Select | 00＝÷1、01＝÷16、10＝÷64、11＝マスタリセット。マスタリセットは状態レジスタを消去し送受信部を初期化する（CTS・DCDの外部状態を除く）。他の制御ビットは変えない |
| CR4:CR2 | Word Select | 000＝7ビット+偶数パリティ+2ストップ、001＝7+奇数+2、010＝7+偶数+1、011＝7+奇数+1、100＝8ビット+2ストップ、101＝8ビット+1ストップ、110＝8+偶数+1、111＝8+奇数+1。変更はバッファされず即時有効 |
| CR6:CR5 | Transmitter Control | 00＝RTS̅低・送信割込み禁止、01＝RTS̅低・送信割込み許可、10＝RTS̅高・送信割込み禁止、11＝RTS̅低・ブレーク送出・送信割込み禁止 |
| CR7 | Receive Interrupt Enable | 1でRDRF、オーバーラン、DCD̅の立上りによる割込みを許可 |

本機の初期化例 [P]：0x03（マスタリセット）を書いたあと、0x95（CR7=1、CR6:5=00、CR4:2=101＝8N1、CR1:0=01＝÷16）を書く。

注意 [D M1 3-498]：電源投入後は CR0・CR1 を両方1にしてマスタリセットが必要。最初のマスタリセット中は IRQ̅ と RTS̅ が高に保たれる。内部のパワーオンリセットは電源立上りが素直であることに依存する。

### 4.3 状態レジスタ [D M1 3-501, 3-502]

| ビット | 名称 | 内容 |
|---|---|---|
| 0 | RDRF | 受信データあり。RDR読出しかマスタリセットで消える。DCD̅が高でも空を示す |
| 1 | TDRE | 送信データレジスタ空。CTS̅が高のときは抑止される |
| 2 | DCD | DCD̅入力が高になると立つ。状態レジスタ→データレジスタの順に読むかマスタリセットで消える |
| 3 | CTS | CTS̅入力の状態。マスタリセットの影響を受けない |
| 4 | FE | フレーミングエラー（最初のストップビットがない） |
| 5 | OVRN | オーバーラン。RDRを読まずに2文字目を受けた場合。RDR読出しかマスタリセットで解除 |
| 6 | PE | パリティエラー |
| 7 | IRQ | IRQ̅出力がアクティブのとき1。RDR読出しかTDR書込みで解除 |

割込みの解除条件：送信割込みはTDRへの書込みで、受信割込みはRDRの読出しで解除する。オーバーランとDCDによる割込みは、状態レジスタを読んだあとRDRを読むと解除される [D M1 3-499]。

## 5. 仕様書との照合

| 仕様書の節・記述 | 判定（一致／不一致／要確認） | 根拠・修正案 |
|---|---|---|
| §04「MC6850系 [10]：非同期シリアルI/O、制御・状態・データレジスタ」 | 一致 | 制御・状態・TDR・RDRの4レジスタ [D M1 3-500]。[10]の1975年資料は未照合のため、1985年以前の根拠として1983年Motorolaデータブック（M1）を§14に追加することを提案 |
| §09「MIDI IN/OUT 5-pin DIN、31.25 kbit/s、8N1。MC6850系＋絶縁入力」 | 一致 | 8N1は CR4:2=101。31.25 kbit/sは500 kHz÷16で得られる [D M1 3-496, 3-501] |
| §09「MIDI_STATUS / MIDI_DATA：上位byte lane」（+0x14／+0x16） | 一致 | RS=A1、D7–D0を68000のD15–D8へ接続すれば成立 [P] |
| §09「3-byteメッセージは約0.96 ms」 | 一致 | 320 µs×3 [D: 計算] |
| §07 クロック領域表 | 要確認 | ACIA用500 kHzが表にない。「ACIA 500 kHz（÷16で31.25 kbit/s）。MC6850は÷16/÷64時0.8 MHz以下」を追加する案 |
| §09「INPUT_IRQ_STATUS：W1C、MIDIはACIA側も処理」 | 要確認 | ACIAのIRQ̅はRDR読出し・TDR書込みでしか解除できない [D M1 3-502]。INPUT_IRQ_STATUSのW1CでACIA要因を消せるかのように読めるため、「MIDIビットはACIAのIRQ̅を反映する読出し専用」とするか、W1Cの対象外と明記する案 |
| §05「未割当・不正幅アクセスは有限時間でバスエラー」 | 要確認 | ACIAはVPA/E同期のため、1アクセスに約10〜18クロックかかる [V]。バスエラー監視（64 CPUサイクル以内）より短いことを確認する |
| §12「MAME等の既存実装（ACIA）を参照」 | 一致 | `6850acia.cpp` は BSD-3-Clause [D MAME1] |
| §14 [10] Motorola 1975 applications manual | 要確認 | 本調査では未照合。M1（1983）を追加すると年代根拠が明確になる |

## 7. 未確定事項 [V]

1. 1985年の国内入手性、第二ソース（日立HD6850／HD68A50等）の品番と価格。
2. VPAサイクルの正確なクロック数（68000データシートの図6-2/6-3、および68000台帳と照合）。
3. MIDI IN のフォトカプラ品番・応答速度、MIDI OUT／THRUのドライバ。MIDI 1.0規格原典（1983）の電気仕様を未照合。
4. ACIA割込みのレベル、オートベクタかINPUT_IRQ_STATUS経由のポーリングか。Data FabricのDMAがバスを長く占有した場合の受信遅延（1バイト320 µsで次の文字が来るため、RDR読出しが約1文字時間以上遅れるとオーバーランになる [D M1 3-501–3-502]、許容値は未評価）。
5. 仕様書[10]の1975年資料の該当ページ。
