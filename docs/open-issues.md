# fc85 未確定事項・整合性課題 台帳

対象：`docs/spec/hardware.md`（v0.2 時点。以下「仕様書」）
更新：2026-11-25（仕様書 v0.2 への改訂に合わせて更新）

仕様書は作業中の版。この台帳では未決の課題を管理する。決めたことはこの台帳に書かず、[decisions.md](decisions.md) に DR-xxx として、理由と却下した案とともに書く。DR を仕様書へ反映したら、課題の状態を「解決（DR-xxx）」にする。

- **種別**：整合（仕様書内の矛盾・計算、文書間の食い違い）／時代（1985年との整合）／リアリティ（当時の設計として不自然）／未定義（仕様の穴）／権利／再現（現代の実装・入手性）
- **状態**：次のどれかを書く。
  - 未着手：まだ調べていない
  - 調査中：調べ始めたが、案はまだない
  - 案あり：調査で案が出たが、決定していない。DR が課題の一部だけを決めたときもこれにし、「関連」に DR を書く
  - 解決（DR-xxx）：DR が課題全体を決め、仕様書に反映した
  - 解決（修正）：資料に基づく記述の誤りや文書間の食い違いを、仕様書や台帳で直した。設計の選択ではないので DR は要らない
- **関連**：調査結果を記録したファイル（`docs/parts/` 配下。拡張子は省略）、決定（DR-xxx）、物語（`docs/story/` 配下）

## 点検で問題がなかった計算

- 256×192・4bpp = 24,576 B。60 Hz片方向で約1.47 MB/s、128×96・8-bit・15 Hzで約0.18 MB/s（§07）
- Fabric理論上限：16-bit × 8 MHz ÷ 4クロック = 4 MB/s（§07）
- 漢字ROM配置：非漢字8区 × 94 × 8 B = 6,016 B、第一水準16〜47区 32区 × 94 × 8 B = 24,064 B、終端 0x7D80（§08）。第一水準2,965字に対し枠は3,008で、空き43枠は47区52点以降と一致する
- DSPプログラム窓：0x280000–0x281FFF = 8 KiB = 4K × 16（§05）
- DOCレジスタ窓：256レジスタ × 2 = 0x200（§05）
- MIDI 3バイト：30 bit ÷ 31,250 bit/s = 0.96 ms（§09）
- CD22101：1980年RCA資料（Preliminary Data）で実在を確認。帯域10 MHzで映像信号も通るが品質は保証されない、という§10の表現は妥当（`parts/CD22101.md`）
- v0.2 のメモリ部品と容量（DR-005、DR-008）：HM6168H（4K×4）×4 = 4K×16 = 8 KiB（DSPプログラムRAM、窓と一致）。HM6264（8K×8）×8 = 64 KiB（Staging、0x120000–0x12FFFF）。4164（64K×1）×16 = 128 KiB（Main、0x100000–0x11FFFF）。27256（32K×8）×2 = 64 KiB（Boot ROM、0x000000–0x00FFFF）。HM4864A（64K×1）×16 = 128 KiB（VRAM）。食い違いはない
- 走査（DR-002）：5.369318 MHz ÷ 342 = 15.700 kHz、÷ 262 = 59.923 Hz
- Main RAMのリフレッシュ（DR-008）：128行 ÷ 5行／ライン = 25.6ライン × 63.695 µs = 1.63 ms（規格は128行／2 ms）
- MIDI（DR-003）：16 MHz ÷ 32 = 500 kHz、÷16 = 31.25 kbit/s（誤差0）
- ACRTC（DR-004）：2CLK 5.369318 MHz の周期186.2 ns は、-8品の下限125 ns以上（HD63484 §1）
- DOC（DR-003）：8 MHz・16オシレータでサンプルレート 8 MHz ÷ 8 ÷ (16＋2) = 55.6 kHz（ES5503 §5）
