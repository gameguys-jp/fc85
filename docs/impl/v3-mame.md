# V3：MAME との照合

IC のコアを、独立した実装（MAME）と同じ入力で動かし、結果を比べる（検証 V3）。コアは台帳（`docs/parts/`）と原典から書いたもので、MAME のコードは写していない（DR-040）。ここでは、照合のやり方と、見つかった差の扱いを書く。

## 01　範囲

| IC | 相手 | 状況 |
|---|---|---|
| TMS32010 | MAME `src/devices/cpu/tms320c1x/`（`tms320c10_device`） | 照合した（§03） |
| HD63484 | MAME `src/devices/video/hd63484.cpp` | まだ |
| ES5503 | MAME `src/devices/sound/es5503.cpp` | まだ |
| MSM5205 | MAME `src/devices/sound/msm5205.cpp` | まだ |
| HD68000 | SingleStepTests（MAME ではない） | 照合した（[emulator.md](emulator.md) §04） |

MAME は GitHub の `mame0289` のタグのものを使う。上の 4 つのファイルは BSD-3-Clause。

## 02　やり方

- **入力の列**は、リポジトリの `tools/v3/<IC>_vectors.py`（Python の標準ライブラリだけ）で作る。乱数の種と件数を引数で渡すので、同じ列を作り直せる。
- **照合の相手**は、リポジトリの外のフォルダ（以下 `<v3>`）に置く。MAME のソースを取ってきて、MAME の枠組みの最小限の代わり（`emu.h` など）と一緒に C++ で組み、入力の列を実行して結果を書き出す。MAME のソース、組んだもの、出力はリポジトリに入れない。
- **照合**は、リポジトリの `emulator/crates/chips/tests/<IC>_v3.rs`。環境変数 `FC85_V3_DIR` に `<v3>` を渡すと、入力と相手の出力を読んで、コアを同じ入力で動かして比べる。ないときは何もせずに合格する。

```
FC85_V3_DIR=<v3> FC85_V3_VERBOSE=2 cargo test --release -p fc85-chips --test tms32010_v3 -- --nocapture
```

`FC85_V3_VERBOSE` は、食い違いの種類ごとに出す例の数。

食い違いは、次の 3 つに分ける。

| 分類 | 意味 | 扱い |
|---|---|---|
| (a) コアの誤り | 資料に書いてあるのに、コアが違う | コアを直し、資料の頁と単体試験を付ける |
| (b) MAME の誤り | 資料、または MAME 自身のほかの命令と食い違う | `<v3>` の側で MAME のソースに手元の直しを当てて照合を続けるか、既知の差として数える。直しはリポジトリに入れない |
| (c) 資料にない動作 | どちらが正しいか、資料では決められない | 既知の差として数え、実チップでの確認（V4）の候補にする |

既知の差は、照合の試験の中に、分類と根拠を付けて書く。既知の差でない食い違いがあれば、その場合（入力の 1 件）はそこで止め、命令と項目の組で数える（その先は状態がずれるので比べない）。

## 03　TMS32010

### 比べるもの

1 命令ごとに、PC、ACC、P、T、AR0、AR1、状態語、スタック 4 段、サイクル数と、その命令のバスの出来事（IN、OUT、TBLW の書込み）、変わったデータ RAM の語を比べる。入力の 1 件は、データ RAM 144 語、IN のポート 8 つの値、BIO、プログラムの 512 語（命令の形を重みにした乱数）。

MAME の側は、1 回の呼出しで 1 命令だけ実行する（`m_icount` を 0 にして `execute_run`）。MAME のリセットは OVM を 1 にするが、本機のコアは TI の資料どおり OVM を変えない（台帳 §3.5、追補 A）。照合では MAME の状態語をコアの初めの状態（0x3EFE）にそろえる。データ RAM は 0〜143 番地で、144〜255 番地は読むと 0、書込みは捨てる（どちらも同じ）。

### 結果（2026-11-26）

| 列 | 件数 × 命令 | 一致 |
|---|---|---|
| 種 1985 | 5000 × 24 | 既知の差のほかはすべて一致。2 件は既知の差（7F の群）で打ち切り |
| 種 2026 | 20000 × 48 | 既知の差のほかはすべて一致（959175 命令）。31 件は既知の差（7F の群）で打ち切り |

### 差と分類

| 項目 | 分類 | コア | MAME | 根拠 | 扱い |
|---|---|---|---|---|---|
| SAR を間接で使い、自分の AR を増減するとき | (a) | 増減の後の値を書く（直した） | 同じ | T3 3-55〜3-56 の WARNING（AR0＝10 で `SAR AR0,*+` は 10 番地に 11、`SAR AR0,*-` は 9）[D] | 以前のコアは「資料にない」として増減の前の値を書いていた。試験 `sar_of_the_stepped_ar_stores_the_new_value` |
| ADDH の OV | (b) | 32 bit の和の桁あふれ（SUBH と同じ） | 足す値をいつも正とみなす（上位の語で符号を見る） | T3 3-11 の演算は (ACC)＋(dma)×2^16 で、SUBH（T3 3-62）と同じ形 [D]。MAME の SUBH は 32 bit で計算する | 手元で直して照合 |
| SST を間接で使うときの次の ARP | (b) | 指定どおりに変える | 変えない | T3 3-59 の書式 `SST {*\|*+\|*-}[,<ARP>]` [D] | 手元で直して照合 |
| 条件分岐が飛ばないときのサイクル数 | (b) | 2 | 1 | 各命令の頁は成否によらず 2（台帳 追補 A、DR-032）[D] | 既知の差（4 万件ほど）。実測は V4 |
| 未定義の命令のサイクル数 | (c) | 1 サイクルの NOP | 0 サイクルで何もしない | 資料にない [V] | 既知の差 |
| 7F の群の未定義の語（7F83 など） | (c) | 1 サイクルの NOP | 下位 5 bit だけで解読し、7FA0〜7FFF を 7F80〜7F9F の命令として実行する | 資料にない [V] | 既知の差。状態がずれるので打ち切る |
| DMOV・LTD で 255 番地を指すとき | (c) | 写さない | 0 番地へ回り込んで写す | 資料にない（台帳 §7 の 6）[V] | 既知の差。MAME の RAM にそろえて続ける |
| SUBC の OV | 一致 | 変えない | 変えない（OV の式はあるが、条件がいつも偽） | T1 の命令の頁は OV に触れない | 以前の emulator.md の「MAME は SUBC で OV を立てる」は誤りだった |

### 比べていないもの

- 割込み：MAME は受付に 3 サイクル、コアは 1 ダミーサイクル（台帳 追補 A、DR-032）。照合の入力に INT は入れない。
- リセットの途中と RS の幅、サイクルの中のバスのストローブ（MAME は命令の単位で動く）。
- 144〜255 番地の読み書き：MAME の側は割り当てのない番地として 0 を返す形にしたので、実チップの動作は比べていない。

### V4（実チップ）の候補

1. 条件分岐が飛ばないときのサイクル数（台帳 §7 の 5）。
2. 未定義の命令（7F の群の解読を含む）の動作とサイクル数。
3. 144〜255 番地を指したときと、DMOV・LTD が 255 番地から写すときの動作（台帳 §7 の 6）。
4. SST を間接で使うときの番地。T3 3-59 は、直接の番地をページ 1 とし、例に `SST DAT1` と `SST *,1`（AR＝1）を並べる。間接もページ 1 になるのか、AR の下位 8 bit なのかは書いていない（コアと MAME はどちらも AR の下位 8 bit）[V]。

## 04　`<v3>` の中身

リポジトリには入れない。作り直すときの手がかりとして書く。

| ファイル | 中身 |
|---|---|
| `fetch.sh` | MAME のタグのソースから、照合に使うファイルを取ってくる |
| `shim/` | MAME の枠組みの最小限の代わり（デバイス、番地の空間、メモリの読み書きの口）。MAME のコードは写していない |
| `tms32010/patch.py` | §03 の (b) の手元の直しを当てた写しを作る |
| `tms32010/harness.cpp` | 写しを組み込み、入力の列を 1 命令ずつ実行して書き出す |
| `tms32010/run.sh` | 入力の列を作り（`tools/v3/tms32010_vectors.py` に件数・命令の数・種を渡す）、組んで動かす |
| `tms32010/cmp.sh` | 照合の試験を動かす |
