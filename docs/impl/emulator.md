### 約束

- IC のコアは、その IC のクロック 1 つを `tick` の 1 回とする。TMS32010 は命令サイクル（CLKOUT の 1 周期＝CLKIN の 4 周期）、ES5503 は DOC サイクル（E の 1 周期＝CLK の 8 周期）、HD63484 は 2CLK の 1 周期を 1 回とする。外部ピンへの入力は `set_*`、出力は `tick` の戻り値と読み出しの関数で返す。IC の外のメモリ（ES5503 の波形 RAM、HD63484 の VRAM）はトレイトの向こうに置き、board 層（または試験）が実装する。クロック領域どうしの合わせ方は core の仕事で、コアは知らない。
- 状態はすべて serde で保存・復元できる（snapshot、Bend のパッチの undo）。
- MAME など既存の実装のコードは写さない。台帳に書き起こした式とタイミングから書く。V3（独立実装との比較）で、比べる相手と独立であるため。
- 台帳で [V] の動作は、どう扱ったかをコードの注釈と §03 に書く。比べたい動作（例：回り込みとクリップ）は設定で切り替えられるようにする。

## 03　仕様との差

### MSM5205

コードは `emulator/crates/chips/src/msm5205.rs`。節の番号は [台帳](../parts/MSM5205.md) のもの。

| 仕様の項目 | 実装での扱い | 理由 | 影響 |
|---|---|---|---|
| オーバーフロー（§4.4） | 12 bit の 2 の補数で回り込むのを標準にし、クリップ（MAME と同じ）を設定で選べる | データシートは回り込み、MAME はクリップ。実 IC の測定はない [V] | Image as ADPCM、字形の ADPCM 化の音 |
| RESET の最小幅（§3.3：V̄C̄K̄ 2 周期以上） | 取込みの時点で RESET が H なら、予測値とステップ番号を 0 にする。最小幅は見ない | 短いパルスのときの動作が資料にない [V] | 短い RESET を使う Bend で、実 IC と違いうる |
| DA OUT の遅れ（§3.2：約 1 周期） | 取込みと同時に予測値を更新する。遅れは扱わない | V2 の比較は取込み列で行う（§6 の注意 5） | 音が 1 サンプル早く出る。アナログの層で足す |
| DAC の精度と LPF（§3.5、§6 の注意 4） | 10 bit のコード（予測値の下位 2 bit を捨てた値）だけを出す | 電圧はアナログの層の仕事 | — |
| 3-bit モード（§4.5） | D0 を 0 にして、4-bit の表に通す（MAME と同じ） | ほかに根拠がない。OKI の数値と合わない可能性がある [V] | 本機は 4-bit が標準 [P] |
| S1＝S2＝H（§4.5） | 内部の分周を止め、V̄C̄K̄ を入力にする（MAME の解釈） | データシートでは禁止 | Bend モードだけで使う [P] |
| 電源投入時の状態 | 予測値とステップ番号は 0、V̄C̄K̄ は H、8 kHz | 資料にない [V] | 使う前に RESET をかける |
| V̄C̄K̄ の位相 | 周期の前半を H、後半を L にする。立下りから 6 クロック後に取り込む | §3.2 | — |
| S1・S2 を周期の途中で変える | 周期の中の位置を保つ。新しい周期を超えていれば、次の周期の頭から数え直す | 実 IC の動作は未確認 [V] | 分周を切り替える Bend |

### TMS32010

コードは `emulator/crates/chips/src/tms32010.rs`。節の番号は [台帳](../parts/TMS32010.md) のもの。命令の意味は TI の資料（台帳の T1・T3）に従った。MAME（台帳の M1）とは照合だけをした。

プログラムメモリ、I/O ポート、BIO ピンは `Bus` トレイトの向こう側に置き、board 層（または試験）が実装する。

| 仕様の項目 | 実装での扱い | 理由 | 影響 |
|---|---|---|---|
| 時間の単位（§3.1） | `tick` の 1 回を 1 命令サイクル（20 MHz の水晶で 200 ns）にする。CLKIN の 4 分周は board 層でする | V2 の比較はサイクル単位で足りる。サイクルの中のストローブの位相（§3.2）は、外から見て効くところが少ない | MEN・DEN・WE のサイクルの中の時刻は出さない。ストローブの幅を使う Bend は、board 層で近似する |
| 命令の先読み（§3.3、§3.4） | フェッチと実行を同じサイクルに置く。サイクル数は §3.7 の表どおり。IN・OUT は 1 サイクル目に、TBLR・TBLW は 2 サイクル目にバスを使う | 外から見えるのは、サイクル数とバスの読み書きの順 | — |
| 条件分岐のサイクル数（追補 A） | 成否によらず 2 | TI の資料を正とした（DR-032） | MAME（不成立は 1）と比べるとき（V3）は既知の差 |
| 割込みの受付（§3.6、追補 A） | 1 ダミーサイクルで PC を積み、2 番地へ移る。次のサイクルで 2 番地の命令を実行する。受け付けない条件は複数サイクル命令の途中と、MPY・MPYK・EINT の次の命令 | TI の図2-12（DR-032） | MAME（3 サイクル）と比べるときは既知の差 |
| INT の入力（§3.6） | 立下りを INTF に保ち、Low の間も要求にする。DINT の間も INTF は残る | §3.6 | ハンドラから戻るとき INT が Low のままなら、すぐ次の割込みになる |

### HD68000

コードは `emulator/crates/chips/src/hd68000.rs`。節の番号は [台帳](../parts/HD68000.md) のもの。命令の時間は台帳 §2.9（DB85 表27〜39、M68 表7-3〜7-16）から組み立てた。SingleStepTests（台帳の SST）とは照合だけをした（データはリポジトリに入れない）。DIVU・DIVS の時間は、解析（台帳の CWIK）が示す段ごとの時間から長除法で導き直した閉じた式（台帳 §2.9）で書いた。GPL のコードの手順は使わない（DR-064）。ほかのエミュレータのコードは写していない。

映像のクロックの模型（コードは `vclock.rs`、`tv.rs`、`acrtc.rs`、`console.rs`）：

- Main RAM（4164-15×16）の行は 68000 の A9〜A16、列は A1〜A8 [P]。行の番地の下位 7 bit で 128 行のリフレッシュ（RA7 の違う 2 行を一度に活性化する）[P]。リフレッシュは HSYNC ごとに 5 行（DR-026、7 bit のカウンタ）。HSYNC が 72 µs 来なければ見張りのカウンタが 5 行（DR-081、`MAIN_REFRESH_WATCHDOG`。CPU の待ちも同じ。`main_refresh_start`）。`dram refresh hsync` で見張りを切る。CPU の読み書きも、その語の行を活性化する。同じ 512 byte を使う作業領域（スタック、変数）は残り、ほかが崩れる。
- VRAM（HM4864A-12×16、128 行／2 ms [D MEM8505 p.192]）の行は ACRTC の語の番地の bit 0〜7、列は bit 8〜15 [P]。リフレッシュの番地が MAD7–0 に出るとし [V]、それを行の番地の線に通すにはこの割当てになる。リフレッシュ、表示の読出し（1 ラインに連続した 65 語で、2 ラインで 128 行を通る）、描画の読み書きが行を活性化する。STR＝0 の間もリフレッシュを続ける [V]。
- 放電した値：RA0＝0 の行は真のセルで 0、RA0＝1 の行は補のセルで 1 [P]（折り返しのビット線で、隣の行が BL と /BL に交互につながるとした。実際の配置は資料にない [V]）。崩れた Main RAM は 512 byte ごとに $00 と $FF、VRAM は 1 語（4 画素）ごとにパレットの 0 番と 15 番の縦の縞になる。
- 崩れるのは、行が次に活性化されたとき（模型の約束。読み書きされるまで配列の値は変わらない）。どのセルが崩れるかは DR-072 の分布と hash。チップの番号は Main RAM が $100＋bit、VRAM が $200＋bit、セルの番号は語の番地。
- 工場出荷のクロックでは、同じ行のリフレッシュの間は Main RAM で最大 26 ライン（1.656 ms）、VRAM で 11 ライン（0.70 ms）で、70 °C の最短の保持 2.21 ms（DR-072）より短い。Main RAM が崩れ始めるのは、70 °C で入力が約 16.1 MHz 以下、25 °C で約 711 kHz 以下。
- 追跡は Bend モードのときだけ。通常モードでは、スロットごとの確かめもしない（`System::sync_time` が分ける）。
- テレビ（機械の外。値はすべて [P][V]、`Tv::default`。状態を持たず、ACRTC のレジスタ、クロック、画面の配列、時刻から毎回絵を作る）：
  - 水平の AFC は、工場出荷の 15699.76 Hz に H-HOLD を合わせ、±500 Hz を引き込む（入力で約 ±3.2%）。絵は差に比例して横にずれ、端で 4 µs。外れると自走のラインの格子で信号を切るので、絵は斜めに裂けて流れる。ラインが自走の 10 倍より長いと、同期として分けられない。
  - 垂直は 55 Hz で自走し、55〜66 Hz を引き込む（入力で −8.2〜＋10.1%）。外れると自走のフィールドの頭から絵を出し、縦に流れる。水平が引き込んでいても、VC を変えたソフトは流れうる。
  - 色の発振は 3579545.45 Hz の水晶で、±500 Hz（入力で ±3 kHz）を引き込み、色相が asin(差÷500 Hz) ずれる（1 次の PLL の定常の位相差）。外れると唸り √(差²−500²) で色相が縦に回り、300 Hz を超えるとカラーキラーが色を消す。水平が外れても色を消す。色相は YIQ で回す。
  - 同期がない（止めた、STR＝0）ときは、出力段が保つ画素の輝度を一様に出す。表示が止まっていれば黒。
  - 工場出荷のクロック（ジャンパなし）と案B では、画面の配列そのまま（ビット単位で同じ）。外部クロックは周期を時刻の単位に丸めて機械を動かすが、テレビは丸める前の周波数で見る（色の ±500 Hz は、21.47727 MHz の周期の 1 単位より細かい）。
  - 引込みの履歴（ヒステリシス）、PLL の過渡、偏向の振幅の変化、ゴーストは作らない。
