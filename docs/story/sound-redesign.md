## 01　要旨

本機の音源は、1985年の開発終盤に急遽 ES5503（Ensoniq DOC）へ差し替えたものである。それまでは TMS32010 のソフトで音楽を合成する計画だった。DOC は旧取引先の縁で試作用サンプルを得たが、量産規模の供給は約束されず、量産断念の一因になった。 [確定]

この物語は次の設計を説明する：DOC の子基板、クロックの流用、出力配線のジャンパ、初期 16 オシレータ、DOC がないときの DSP 合成、MSM5205 が残ること（[DR-011](../decisions.md)）。

## 03　詳細

### FM を採らなかった理由

1985年の国産機では、ヤマハの FM 音源が標準だった。本機は録音した音、文字の字形、画像の行などを、そのまま波形として鳴らす装置を目指した。FM はパラメータから音を作る方式で、任意のデータを波形として再生できない。そのため FM を見送り、DSP によるソフト合成を選んだ。 [確定]

### DSP の選び方

メーカーは通信機器で NEC µPD7720 を使ったことがあった。しかし µPD7720 はプログラムを内蔵 ROM（または紫外線消去の EPROM）に置く方式で、用途ごとにプログラムを差し替えられない。外部 RAM のプログラムを全速で実行できる TMS32010 を選んだ（[review-signal.md](../parts/review-signal.md)）。 [確定]

### Ensoniq 側の事情

1985年の Ensoniq は Mirage の生産で手一杯で、欧州向けはイタリアでライセンス生産していた（[supply-ES5503.md](../parts/supply-ES5503.md) §5）。DOC のデータシートは用途に「アーケードや家庭用ビデオゲーム」を挙げており、外販の可能性はあった（同 §7b）。昔の取引先の技術者に試作用の数十個を渡すことはできても、量産の数万個は約束できなかった。 [確定]

同じ年に Apple も、契約前の DOC を新しい機種の設計に組み込んでいた（[supply-ES5503.md](../parts/supply-ES5503.md) §0・§3）。メーカーがそれを知っていたかどうかは決めない。 [確定]

### 差し替えの跡

| 跡 | 内容 | 類例 |
|---|---|---|
| 子基板 | DOC、波形 RAM 64 KiB、アダプタ、出力アンプを子基板に載せる | Apple IIGS のブロック図で音源部だけがオプション扱い（[supply-ES5503.md](../parts/supply-ES5503.md) §6） |
| クロックの流用 | DOC は既存の 16 MHz を 2 分周した 8 MHz で動かす | Apple IIGS も DOC のクロックを既存の系から取った（同 §6） |
| 出力配線 | 差動出力の両側にアンプを入れる。初期の片側だけの配線をジャンパで選べる形で残す（Bend モードの材料） | Apple IIGS の出力回路の試行錯誤（同 §6） |
| オシレータ数 | 初期のソフトは 16 オシレータだけを使う | — |
| DSP 合成への切り替え | DOC の子基板がないときは、DSP のソフト合成で音を出す | 供給元が1社だけの部品への備え |
| MSM5205 | 1983年の音声用が残る。旧ソフトと素材の互換のため | — |

### 守ること

- メーカーを Mirage の輸入元・製造元にしない。日本での Mirage の販売と生産は、後年に別の会社が担った（[supply-ES5503.md](../parts/supply-ES5503.md) §4）。
- 実在の人物の名前を出さない。「Ensoniq の創業者たち」「メーカーの技術者」と役割で書く。
- 1985年に DOC の外販契約があったことにしない。試作用の少量サンプルにとどめる。
