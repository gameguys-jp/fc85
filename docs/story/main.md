## 01　要旨

日本の中堅業務用電子機器メーカーが、業務用の文字表示・映像・通信の技術を家庭向けに転用し、1985年に家庭用多目的コンピュータの最終試作機を完成させた。機能を盛り込みすぎて家庭用として採算が合わず、音源ICの量産供給も確保できず、量産を断念した。 [確定]

この物語は機械の設計に直接効いている（N3〜4）。設計上の帰結は §04 に挙げ、仕様書と決定記録へリンクする。

## 03　詳細

### メーカーの気質

メーカーの特徴は「盛り癖」。業務用の技術を惜しみなく採用し、用途を広げてしまう。デザインディレクターは、複雑な内部を一貫した操作で扱えるようにする役割を担う。 [確定]

### JIS 改正の扱い

JIS 改正は技術的に解決できない事故ではなく、延期の一因とする。旧規格の維持、変換表、ROM の作り直しといった回避策はある。既存の開発環境との互換性を残すため、最終試作機でも旧字形の ROM を使い、新 ROM への更新案も残す。 [確定]

### 量産断念の理由

主因は原価。家庭用の価格に収まらない部品点数と基板構成になった。DOC の供給は一因で、Ensoniq は1985年に自社製品の生産で手一杯だった（[supply-ES5503.md](../parts/supply-ES5503.md) §5）。試作用の数十個は出せても、量産の数万個の約束はできなかった（[音源の差し替え](sound-redesign.md)）。 [確定]

### 未確定の項目

氏名、社名、製品名、筐体、ロゴ、内蔵 UI は確定しない。決定記録を経ずに確定させない。 [確定]

### 後継

将来は第二世代（1989〜92年頃）、第三世代（1994〜96年頃の3D機）などへ設計文化を継承する。後継機の具体的な仕様や発売状況は未決定。 [仮]

## 04　設計への反映

| 物語の要素 | 機械での表れ | 正 |
|---|---|---|
| 媒体を作り・変換し・交換する装置 | 異種 IC と Data Fabric、A/V の双方向処理 | [仕様書](../spec/hardware.md) §02・§03 |
| ゲーム入力の意味を固定しない | 外部楽器・ノブ・スイッチ・センサーを入力に使える。コントローラとゲームの意味づけを分ける | 仕様書 §02・§09 |
| カートリッジなしでも使える | 内蔵 BIOS に文字描画・入出力・転送の共通機能。診断と基本操作 | 仕様書 §02・§05 |
| JIS 改正 | 漢字 ROM は JIS78 基準、JIS83 は差分 ROM イメージ | 仕様書 §08 |
| 1983年の音の名残 | MSM5205 が最終試作機にも残る | [DR-006](../decisions.md)、[音源の差し替え](sound-redesign.md) |
| 1985年の差し替え | DOC の子基板、クロックの流用、出力配線のジャンパ | [DR-011](../decisions.md) |
| 主な調達先が日立 | HD68000、HD63484、HD6850、日立のメモリ | [DR-008](../decisions.md)、[出自](company-origin.md) |
