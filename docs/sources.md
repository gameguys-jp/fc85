物語と仕様が依存する、部品以外の史実（規格、サービス、企業の動き、他機種の機能）の出典を集める。部品そのものの事実は `parts/` に書く。

凡例：`[D 資料ID 頁]` 出典あり。`[V]` 未確認。「推定」は本台帳での推論。「計算」は資料の数値からの計算。資料ID は末尾の資料一覧を参照。

資料の区分：**当時** はその出来事の時期（遅くとも1985年まで）に出た資料。**後年** は1986年以降の資料。**Wikipedia** は参照日の版。年代の根拠には当時の資料を使い、後年の資料と Wikipedia は補助とする。

実在の人物は、資料の書誌（著者名）以外には書かない。

## 01　JIS C 6226 の1983年改正（OI-035、OI-009）

### 事実

| # | 事実 | 根拠 |
|---|---|---|
| 1-1 | JIS C 6226「情報交換用漢字符号系」は1978年（昭和53年1月1日）に制定された。常用漢字表と改正人名用漢字別表の施行（1981-10-01）などに伴い、1983年9月1日付で改正され、JIS C 6226-1983 になった | [D SUIRO85]（当時）。同じ日付 [D WPJIS] |
| 1-2 | 1978年版は 6,802 字。一般記号 108、漢字 6,349。罫線素片の群はない。空き 2,034 | [D ISOIR42 p.1–2]（当時） |
| 1-3 | 1983年版は 6,877 字。一般記号 147、漢字 6,353、罫線素片 32。空き 1,959 | [D ISOIR87 p.1–2]（当時） |
| 1-4 | 差は、一般記号 +39、漢字 +4、罫線素片 +32 | 計算（1-2、1-3） |
| 1-5 | 罫線素片は8区に置かれた | [D ISOIR87 p.3 の符号表]（当時）。「罫線素片の新設」[D WPJIS] |
| 1-6 | 漢字の変更：(1) 互いに異体字の第1水準と第2水準の 22 組で区点を入れ替えた（例：36区59点と52区68点）。(2) 第1水準3字と第2水準1字を空きの84区へ移し、元の区点に異体字を入れた（例：22区38点を新しい字にし、元の字を84区1点へ）。(3) 約300字の字形を変えた（294字とする文献がある） | [D WPJIS]（典拠は野村 1984「JIS C 6226 情報交換用漢字符号系の改正」標準化ジャーナル 14(3)。原文は未見 [V]） |
| 1-7 | 1985年の報告は、JIS83 は常用漢字の略字体の考えを常用漢字以外にも広げ、JIS78 の字体の変更や入れ替えを行った、と書く。第2水準は JIS78 より4字多い | [D SUIRO85]（当時） |
| 1-8 | 1983年版の原案は、常用漢字表、人名用漢字別表、郵政省の日本語テレテックス標準化の検討をふまえ、24ドット字形の規格（JIS C 6234-1983）と歩調を合わせて作られた | [D WPJIS] |
| 1-9 | 両版は ISO の国際登録簿に別々に登録された。1978年版は ISO-IR 42（1979-12-30 登録、指示の終端 4/0）、1983年版は ISO-IR 87（1984-07-01 登録、終端 4/2）。通信では、どちらの版かをエスケープシーケンスで区別する | [D ISOIR42 p.1; ISOIR87 p.1]（当時） |
| 1-10 | 1985年の雑誌広告に、「新JIS規格対応」の24ドットプリンタ（NEC）と、「新JIS第2水準漢字標準装備」の漢字プリンタ（スター精密）がある | [D MC8511; MC8512]（当時） |
| 1-11 | 実機の漢字 ROM の一覧では、PC-8801mkII／SR、PC-9801F／M、X1turbo、FM-7／FM-77、SMC-777、MZ-2500、MSX 系などの 16×16 ドット ROM は JIS78 である。JIS83 の 16×16 ドット ROM は FM77AV20／40 系などに見られる。24ドットのプリンタ用 ROM には JIS83 品がある | [D KROM]（後年。実物の ROM の記録） |
| 1-12 | PC-9801 シリーズは ROM の字形とコードを旧 JIS のまま、MS-DOS の時代まで使い続けた、とする記事がある | [D KZN]（後年） |
| 1-13 | PC-9800 シリーズの漢字 ROM は1983年末の PC-9801F から標準搭載になった | [D WPKROM] |

1985年中に JIS83 の 16×16 ドット漢字 ROM を載せた国産パソコンは、今回の資料では見つからない [V]。ワープロ専用機の移行の時期は未確認 [V]。

## 05　市販 IC とつなぎ回路で組む設計（補足）

物語で「工場を持たないメーカーが、市販 IC とつなぎ回路で組む設計を原則にした」と書くための裏付けを探した。

### 事実

| # | 事実 | 根拠 |
|---|---|---|
| 5-1 | 放送用カメラなどの映像機器メーカーの池上通信機は、1980年代初めにゲーム会社の下請けとしてアーケードゲームを開発した（Radar Scope、Donkey Kong、Zaxxon など） | [D WPIKE]（Wikipedia。典拠は2005年の書籍） |
| 5-2 | Donkey Kong（1981）の基板は、Radar Scope の4枚組の基板（TRS-02）を元にした。のちに2枚組（TKG-4）になった。Radar Scope の基板を改造して Donkey Kong に転換した版がある。音は I8035 で鳴らす | [D MAME-DKONG]（後年。回路図と実機基板の記録） |
| 5-3 | セガ SG-1000（1983）の基板は、Z80A（NEC µPD780C-1 または Zilog）、TI の TMS9918A（映像）と SN76489A（音）、富士通の MB8118 で組む | [D MAME-SG1000]（後年。実機基板の記録） |
| 5-4 | セガ System 16A（1985〜）は、68000、Z80A、YM2151、µPD7751C に、カスタム IC と PAL16R6 を組み合わせる | [baseline-1985.md](parts/baseline-1985.md) §1 |
| 5-5 | PAL は1983年の MMI のハンドブックにあり、1985年の MMI のデータブックに日本法人の記載がある。国産の PAL 相当品は未確認 | [review-digital.md](parts/review-digital.md) §4.2 |
| 5-6 | 1985年の硬貨式キャプテン端末は、業務用ゲーム機の業界紙に載った地方の2社が「業務用 TV ゲーム機の形式」で共同開発した。会社の規模と、中身の構成は不明 | [D GM85 p.21]（当時） |
| 5-7 | 対照：半導体部門を持つ日立は、キャプテン端末の漢字 ROM をカスタム LSI で作った | [D HH8505A p.359]（当時） |

### 結論

工場を持たない中堅の業務用電子機器メーカー（端末、映像機器、通信機器）が、市販 IC を手を加えずに使い、IC ごとのつなぎ回路（グルーロジック、PAL）や子基板で異なる用途の IC を組み合わせることを、設計の方針として書いた資料は見つからなかった。

見つかったのは間接の例だけである。映像機器メーカーが他社のゲーム基板を受託で開発した（5-1）。市販の IC と TTL で組んだ基板や、既存の基板を改造して別の製品にした例がある（5-2・5-3）。1985年には業務用の基板で PAL を使っていた（5-4）。これらは、当時ありふれた作り方だったことを示すが、「原則」の記録ではない。

### 物語との照合

| 物語の記述（予定） | 照合 | 案 |
|---|---|---|
| 工場を持たないメーカーが、市販 IC とつなぎ回路で組む設計を原則にした | 直接の裏付けはない。矛盾する資料もない | [架空]（メーカーの設計文化）として書き、類例として本節へリンクする。[史実] とは書かない |

## 06　未確認の事項

1. JIS C 6226-1983 の規格票と、野村（1984、標準化ジャーナル 14(3)）の原文。22組の区点の一覧と、字形を変えた字の数（約300字・294字）を原典で確かめる。
2. 1983〜85年に JIS83 へ移ったワープロ専用機と業務用端末の例。1985年中に JIS83 の漢字 ROM を載せた国産パソコンの有無。
3. キャプテンの実験期（1979〜84）に端末を作ったメーカーの一覧。端末の表示制御に使った IC の品番。商用開始日（11月30日）の原紙。高岳製作所の端末の時期。硬貨式端末の社名の表記（大平・太平）。
4. Commodore の日本の組立が終わった年月と、香港の新工場の開設時期。1985年以前の資料にある日本の下請けの名前。CIHS21 の典拠。
5. X1 の記事・広告の頁番号と、CZ-800D の仕様表の数値（原本の画像で確認）。
6. 中堅メーカーの設計の方針を書いた当時の資料（社史、技術誌の記事など）。
