## 2. ピンと本機での接続

ピン番号は R1 の端子図（CD22101 Terminal Diagram、上面図）による [D R1 589]。本機の接続は仕様書§09の予約域（0x260020–3E「アナログマトリクス」）と§10の音響経路を前提にした暫定案。

| 信号 | 方向 | 機能 | 本機での接続 | 状態 |
|---|---|---|---|---|
| B (1) | 入力 | アドレス（Xの上位） | 制御ラッチ出力 bit1（レベル変換後） | 機能 [D R1 589, 591]／接続 [P] |
| C (2) | 入力 | アドレス（Yの下位） | 制御ラッチ bit2 | 同上 |
| X2' (3) | アナログ | 第2アレイ X2 | 音源出力等（右チャネル系） | [D R1 589]／[P] |
| Y1' (4) | アナログ | 第2アレイ Y1 | ミキサ・フィルタ入力等 | 同上 |
| Y2' (5) | アナログ | 第2アレイ Y2 | 同上 | 同上 |
| X4' (6) | アナログ | 第2アレイ X4 | 同上 | 同上 |
| X3' (7) | アナログ | 第2アレイ X3 | 同上 | 同上 |
| Y4' (8) | アナログ | 第2アレイ Y4 | 同上 | 同上 |
| Y3' (9) | アナログ | 第2アレイ Y3 | 同上 | 同上 |
| X1' (10) | アナログ | 第2アレイ X1 | 同上 | 同上 |
| D (11) | 入力 | アドレス（Yの上位） | 制御ラッチ bit3 | [D R1 589, 591]／[P] |
| VSS (12) | — | 負側電源 | 単電源ならGND、両電源なら負電源（例 −6 V） | [D R1 589]／[P]、[V] |
| STROBE (13) | 入力 | 1でアドレスの点にDATAを書き込む | グルーロジックが生成する書込みパルス | [D R1 589, 591]／[P] |
| DATA (14) | 入力 | 1＝ON、0＝OFF | 制御ラッチ bit4 | [D R1 591]／[P] |
| X1 (15) | アナログ | 第1アレイ X1 | 音源出力等（左チャネル系） | [D R1 589]／[P] |
| Y3 (16) | アナログ | 第1アレイ Y3 | 行き先 | 同上 |
| Y4 (17) | アナログ | 第1アレイ Y4 | 行き先 | 同上 |

| Y2 (20) | アナログ | 第1アレイ Y2 | 行き先 | 同上 |
| Y1 (21) | アナログ | 第1アレイ Y1 | 行き先 | 同上 |
| X2 (22) | アナログ | 第1アレイ X2 | 入力源 | 同上 |
| A (23) | 入力 | アドレス（Xの下位） | 制御ラッチ bit0 | [D R1 589, 591]／[P] |
| VDD (24) | — | 正側電源 | +12 V（単電源案）または+6 V（±6 V案） | [D R1 589]／[P] |

デコーダ真理値表 [D R1 591]：X番号＝A＋2B＋1、Y番号＝C＋2D＋1（例：ABCD=1000→X2Y1、0001→X1Y3、1111→X4Y4）。各アドレスは X‑Y と X'‑Y' の対を同時に選ぶ。

X/Yは双方向（トランスミッションゲート）であり、「入力」「出力」の区別は回路側で決める [D R1 590 Fig.1「SIGNALS IN (OUT)」]。

接続上の注意：
- 制御入力はCOS/MOSレベルで、VDDを12 Vにすると5 V TTLから直接は駆動できない可能性が高い。レベル変換（プルアップ付きオープンコレクタ、CMOSレベルシフタ等）が必要 [V]（1980年資料にVIH/VILの記載なし。H1にはVIH最小3.5 V（VDD=5 V）の記載あり [D H1]）。
- 同時に何点でもONにできるため、同じY線に複数の低インピーダンス出力をつなぐと出力どうしが短絡する [D R1 589]。仕様書§10の「複数の低インピーダンス出力をスイッチで直結しない」に従い、X側に直列抵抗またはバッファを置く [P]。

### 3.3 用途の適否（本機）

| 用途 | 判定 | 根拠 |
|---|---|---|
| 音声（DOC・ADPCM・外部入力の経路切替） | 適。メーカー自身が「スタジオ音声切替」を用途に挙げる。歪み0.25〜0.4%、OFF時フィードスルー−95 dB（低周波） | [D R1 589, 592] |
| CV・低速変調信号 | 適。ただし信号はVSS〜VDD内に限る。±5 V級の双極CVは±6 V等の両電源と制御線のレベル変換、または直流オフセットが必要 | [D R1 589]／回路 [P]、[V] |

## 4. レジスタ・制御

CD22101自体はアドレス入力とラッチだけを持ち、読み出しレジスタはない [D R1 589, 591]。

### 4.1 制御の真理値表（CD22101） [D R1 591]

| 動作 | アドレス ABCD | STROBE | DATA | 対象 |
|---|---|---|---|---|
| ON | 例 1111 | 1 | 1 | X4Y4 と X4'Y4' |
| OFF | 例 1111 | 1 | 0 | X4Y4 と X4'Y4' |
| 変化なし | XXXX | 0 | X | — |

### 4.2 電源投入時の扱い [D R1 589]

電源投入直後の16点の状態は不定。STROBEを高、DATAを低にして全アドレスを順に指定し、全点をOFFにする必要がある（CD22102はKa=Kb=1で一括OFF）。「VDD印加時に全クロスポイントをOFFにしなければならない」とも書かれている。

本機の扱い [P]：
- BIOSのリセット処理の最初に全16点をOFFにする。それまでは出力段をミュートしておく（不定状態で音源出力どうしが短絡するのを防ぐ）。
- 制御レジスタ案：MATRIX_CTRL（0x260020）bit3:0＝アドレス、bit4＝DATA。書込みでグルーロジックがSTROBEパルス（≥80 ns、VDD=12 V時の標準値）を出す。チップの状態は読めないため、シャドウレジスタ（各点1ビット×16）をグルーロジックまたはBIOSが持つ。
- 複数個使う場合はチップ選択ビットを追加する（仕様書§04「必要なら複数個」）。
- [O] 一括OFFが要るならCD22102（Ka/Kb）を選ぶ。
