十字キー、Z = A、X = B、C = C、Enter = START（ホストと同じ）。画面を押してから。 ゲームパッドは、十字か左の棒、下の釦 = A、右 = B、左 = C、START（つないで釦を押すと読み始める）。 サンプルを選び直すと、その場で読み込み直す。サンプルの使い方は sdk/samples/<名前>/README.md。 「速さを測る」は、今の場面を写した別の仮想機を 240 フレーム止まらずに進めた 1 フレームの時間（実時間は約 16.7 ms）。 読み込んでから十数秒は、ブラウザが機械語を組み直すので遅い。 「ベンド」は仕様書 §11 のベンド点の命令で、ホストの --bend と同じ書き方（例 mode bend、clock doc 4000000。 使い方は sdk/samples/bend/README.md）。読み込み直すと通常に戻る。 「MIDI を使う」で、ブラウザの Web MIDI の装置を選ぶ（ブラウザが許可を求める）。MIDI IN の byte は仮想機の ACIA（31.25 kbit/s）に入り、ROM が送った MIDI OUT は、その時刻の音が鳴るときに送る（SysEx は送らない）。 「Audio IN」は背面の音声入力（DR-129）：マイク・ライン入力（ブラウザが許可を求める。エコーの除去と自動の 音量は切る）か、音のファイル（ブラウザが読める形式）。0 dBFS が ±1 V で、ミキサと DOC の A/D に入る。
